What changes between Offline and Online?

Offline · Local replay

Replay the sample purchases on this computer. Approvals, refusals and your confirmations are recorded locally.

Online · API simulation

Receive purchases from the test API and send decisions and your confirmations back to it. An approval is counted once the API accepts it. The local API emulator is labelled separately when used.

Both modes use the same spending rules and safety checks. Both use synthetic data: no real payments.

Activity, drafts and learned profiles stay separate. Switching modes changes the view; a run already started continues on the server.

Offline describes the purchase source. If AI decoding is enabled, “Decode instruction” still uses OpenAI over the Internet in either mode. With AI disabled, permissions use the local parser.

The mode label identifies the selected source. It is not a connection test; API errors appear when a request fails.
